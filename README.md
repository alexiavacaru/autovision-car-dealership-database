# AutoVision Car Dealership Database (SQL Project)

This academic project focuses on designing and implementing a relational database for a car dealership, aiming to efficiently manage vehicles, customers, sales, warranties, and repairs.

## Project Overview
- Design of a conceptual and relational database schema for an auto sales company
- Centralization of business data related to cars, clients, transactions and warranties
- Support for operational and managerial decision-making through structured queries

## Database Implementation
- Creation and modification of tables using SQL (CREATE, ALTER, DROP)
- Data manipulation operations (INSERT, UPDATE, DELETE)
- Definition of constraints to ensure data integrity and consistency

## Advanced SQL Features
- Complex SELECT queries, subqueries and hierarchical queries
- Use of views, indexes, sequences and synonyms for database optimization
- Aggregations and conditional logic for reporting and analysis

## Outcome
The project demonstrates the practical use of SQL and Oracle database concepts to model real-world business processes and generate meaningful insights from structured data.
